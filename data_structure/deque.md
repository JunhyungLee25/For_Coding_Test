### 정의

`std::deque`(Double-Ended Queue)는 **양쪽 끝에서 삽입과 삭제가 모두 가능한** 선형 자료구조이다. `vector`의 확장된 형태로 볼 수 있으며, 앞뒤 어디에서나 데이터를 효율적으로 관리할 수 있다.

### 핵심 원리

- `vector`가 하나의 연속된 메모리 블록을 사용하는 것과 달리, `deque`는 여러 개의 작은 메모리 블록(Chunk)을 할당하여 이를 관리한다. 이러한 구조 덕분에 새로운 원소를 앞에 추가할 때 기존 원소들을 뒤로 밀어낼 필요 없이 새로운 블록을 할당하여 연결하기만 하면 된다.
    

### 주요 특징

- **양방향 접근:** 맨 앞(`push_front`, `pop_front`)과 맨 뒤(`push_back`, `pop_back`)의 데이터 추가 및 삭제가 모두 $O(1)$의 시간 복잡도를 가진다.
    
- **무작위 접근(Random Access):** `at()`이나 `[]` 연산자를 통해 특정 인덱스에 $O(1)$로 접근할 수 있다. 다만, 메모리가 물리적으로 완전히 연속되지는 않아 `vector`보다는 미세하게 느릴 수 있다.
    
- **중간 삽입/삭제:** 중간에 데이터를 삽입하거나 삭제하는 경우, 해당 위치 이후의 원소들을 이동시켜야 하므로 $O(N)$의 시간이 소요된다.
    
- **헤더:** `<deque>` 헤더를 포함해야 한다.
    

### 핵심 함수 

**1. 삽입 (Insertion)**

- `push_front(데이터)`: 덱의 맨 앞에 데이터를 추가한다. ($O(1)$)
    
- `push_back(데이터)`: 덱의 맨 뒤에 데이터를 추가한다. ($O(1)$)
    
- `insert(iterator, 데이터)`: 특정 위치에 데이터를 삽입한다. (이후 원소들을 밀어야 하므로 $O(N)$)
    

**2. 삭제 (Deletion)**

- `pop_front()`: 덱의 맨 앞 원소를 제거한다. 반환값은 없다. ($O(1)$)
    
- `pop_back()`: 덱의 맨 뒤 원소를 제거한다. 반환값은 없다. ($O(1)$)
    
- `erase(iterator)`: 특정 위치의 원소를 제거하거나 범위를 지정해 제거한다. ($O(N)$)
    
- `clear()`: 모든 원소를 제거한다.
    

**3. 접근 (Access)**

- `front()`: 맨 앞 원소의 참조를 반환한다.
    
- `back()`: 맨 뒤 원소의 참조를 반환한다.
    
- `operator[i]` 또는 `at(i)`: $i$번째 인덱스 원소에 접근한다. ($O(1)$)
    

**4. 크기 및 상태 (Size/Status)**

- `size()`: 현재 원소의 개수를 반환한다.
    
- `empty()`: 덱이 비어있으면 `true`, 아니면 `false`를 반환한다.
    
- `resize(n)`: 덱의 크기를 $n$으로 변경한다.

### 주요 특징

- **`vector`와의 차이점:** `vector`는 `push_front()`가 없거나 $O(N)$이지만, `deque`는 $O(1)$이다.
    
- **`queue`와의 차이점:** `queue`는 중간 원소에 인덱스로 접근할 수 없지만, `deque`는 `dq[i]`와 같이 임의 접근이 가능하다.
    
- **메모리 구조:** 연속된 메모리가 아닌 여러 블록으로 나뉘어 관리되므로, 아주 큰 데이터를 다룰 때는 `vector`보다 메모리 할당 오버헤드가 조금 더 클 수 있다.

### c++ 구현 예시

```c++
#include <iostream>
#include <deque>
using namespace std;

void dequeExample() {
    // 덱 선언
    deque<int> dq;

    // 뒤에 데이터 추가
    dq.push_back(10); // [10]
    dq.push_back(20); // [10, 20]

    // 앞에 데이터 추가
    dq.push_front(5);  // [5, 10, 20]
    dq.push_front(1);  // [1, 5, 10, 20]

    // 데이터 접근
    cout << "맨 앞: " << dq.front() << endl; // 1
    cout << "맨 뒤: " << dq.back() << endl;  // 20
    cout << "인덱스 2의 값: " << dq[2] << endl; // 10

    // 데이터 삭제
    dq.pop_front(); // [5, 10, 20]
    dq.pop_back();  // [5, 10]

    // 크기 확인
    cout << "현재 크기: " << dq.size() << endl; // 2
}
```
