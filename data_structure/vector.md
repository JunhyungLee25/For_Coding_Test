정의
std::queue가 선입선출의 원칙을 따른다면, std::vector는 동적 배열(Dynamic Array) 구조로, 실행 중에 크기를 자유롭게 변경할 수 있는 연속된 메모리 구조의 컨테이너이다.

핵심 원리
일반 배열과 마찬가지로 메모리상에 요소들이 연속적으로 배치되어 있다. 따라서 인덱스를 통한 임의 접근(Random Access)이 매우 빠르다.

설정된 용량(Capacity)이 가득 차면, 더 큰 메모리 공간을 새로 할당하고 기존 요소들을 복사하는 방식으로 크기를 확장한다.

주요 특징
임의 접근: 인덱스([] 연산자)를 사용하여 $O(1)$의 시간 복잡도로 특정 요소에 접근할 수 있다.

동적 확장: 데이터의 개수에 따라 자동으로 메모리 크기가 조절된다.

끝점 작업: 제일 뒤에 데이터를 추가하거나 삭제하는 연산은 $O(1)$의 시간 복잡도를 가진다. (단, 중간에 삽입/삭제할 경우 요소들을 밀거나 당겨야 하므로 $O(N)$이 소요된다.)

헤더: <vector> 헤더를 포함해야 한다.

동작 방식
push_back: 벡터의 맨 뒤에 새로운 원소를 추가한다.

pop_back: 벡터의 맨 뒤에 있는 원소를 제거한다.

size: 현재 벡터에 저장된 원소의 개수를 반환한다.

resize: 벡터의 크기를 강제로 변경한다. 늘어난 공간은 기본값으로 초기화된다.

clear: 모든 원소를 제거하여 크기를 0으로 만든다.

c++ 구현 예시
C++
#include <iostream>
#include <vector>
using namespace std;

void vectorExample() {
    // 1. 선언 및 초기화
    vector<int> v; // 빈 벡터 생성
    vector<int> v2(5, 1); // 크기가 5이고 모든 원소가 1로 초기화된 벡터

    // 2. 데이터 추가
    v.push_back(10); // [10]
    v.push_back(20); // [10, 20]

    // 3. 데이터 접근 및 수정
    v[0] = 30; // [30, 20]

    // 4. 데이터 삭제
    v.pop_back(); // [30]

    // 5. 반복문을 이용한 탐색
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << " ";
    }

    // 6. 2차원 벡터 선언 (사용자 질문 관련)
    // n행 k열의 2차원 배열을 0으로 초기화
    int n = 3, k = 4;
    vector<vector<int>> matrix(n, vector<int>(k, 0));
}
