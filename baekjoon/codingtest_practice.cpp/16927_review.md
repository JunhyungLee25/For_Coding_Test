1. 문제 분석
    
    이 문제는 $N \times M$ 격자에서 테두리별로 배열을 반시계 방향으로 $R$번 회전시키는 시뮬레이션 문제이다. $R$이 최대 $10^9$으로 매우 크기 때문에 단순 반복으로는 해결할 수 없으며 수학적 최적화가 필수적이다.
    

핵심 로직 (3단계):

- 테두리별 독립적 회전: 배열의 최소 크기($N, M$)를 기준으로 $\min(N, M) / 2$개의 테두리가 존재하며, 각 테두리는 서로 영향을 주지 않고 독립적으로 회전한다.
    
- 주기성을 이용한 최적화: 각 테두리의 둘레 길이를 계산한다. 한 바퀴를 도는 데 필요한 이동 횟수(둘레)로 $R$을 나눈 나머지($R \pmod{\text{perimeter}}$)만큼만 회전시켜 연산 횟수를 획기적으로 줄인다.
    
- 배열 원소 이동: 데이터를 한 칸씩 밀어내는 방식은 데이터 손실이 발생할 수 있으므로, 빈칸을 향해 다음 칸의 값을 당겨오는(Pull) 방식을 사용하거나 임시 변수를 활용해 회전을 구현한다.
    

2. 배운 점
    
    (1) 모듈러 연산의 활용: $R$의 범위가 매우 클 때, 작업의 주기성을 찾아내어 불필요한 반복을 제거하는 것이 성능 최적화의 핵심임을 배웠다.
    
    (2) 레이어별 경계 제어: 안쪽 테두리로 들어갈수록 시작점은 $(i, i)$로 증가하고, 끝점은 $(N-1-i, M-1-i)$로 감소한다. 각 테두리에 맞는 정확한 인덱스 범위를 설정하는 법을 익혔다.
    
    잘못 생각한 부분: 처음에는 모든 테두리가 동일하게 4번 회전하면 제자리로 돌아온다고 생각했으나, 실제로는 각 테두리의 둘레 칸 수만큼 회전해야 제자리로 돌아온다는 사실을 파악하고 공식을 수정하여 해결했다.
    
3. 최종 코드 및 동작 방식 정리
    
    각 테두리에 대해 최적화된 회전 횟수를 계산한 뒤, 반시계 방향으로 원소를 한 칸씩 당기는 방식을 사용한다.
    

작동 방식:

- 둘레 계산: $i$번째 테두리의 세로 길이는 $N-2i$, 가로 길이는 $M-2i$이므로 둘레는 $2 \times (N-2i + M-2i) - 4$가 된다.
    
- 회전 최적화: `R % 둘레`를 통해 실제 필요한 최소 회전 횟수만큼만 `rotate(i)` 함수를 반복 호출한다.
    
- 방향 벡터 활용: `dr`, `dc`를 활용하여 반시계 방향(우-하-좌-상 순서로 당기기)으로 탐색하며 값을 이동시킨다.
    
- 데이터 보존: 시작점의 값(`startVal`)을 미리 저장해두었다가 회전이 끝난 후 알맞은 위치(`map[i+1][i]`)에 배치하여 데이터 유실을 방지한다.
    

구현 코드:

```c++
#include<iostream>
#include<algorithm>
using namespace std;

int N, M, R;
int dr[4] = {0, 1, 0, -1};
int dc[4] = {1, 0, -1, 0};
int map[301][301];

void rotate(int i) {
    int startVal = map[i][i];
    int k = 0;
    int r = i;
    int c = i;
    while (k < 4) {
        int nr = r + dr[k];
        int nc = c + dc[k];
        
        // 시작점으로 돌아오면 회전 종료
        if (nr == i && nc == i) break;
        
        // 현재 테두리 범위 내에 있는지 확인
        if (nr >= i && nc >= i && nr < N - i && nc < M - i) {
            map[r][c] = map[nr][nc];
            r = nr;
            c = nc;
        }
        else {
            k++; // 범위를 벗어나면 방향 전환
        }
    }
    map[i + 1][i] = startVal; // 보관했던 시작값 배치
}

int main(void) {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    cin >> N >> M >> R;
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            cin >> map[i][j];
        }
    }

    int cnt = min(N, M) / 2; // 테두리 개수
    for (int i = 0; i < cnt; i++) {
        // 각 테두리별 둘레 계산 및 최적화
        int perimeter = 2 * (N - 2 * i + M - 2 * i) - 4;
        int k = R % perimeter;
        for (int j = 0; j < k; j++) {
            rotate(i);
        }
    }

    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            cout << map[i][j] << ' ';
        }
        cout << '\n';
    }
    return 0;
}
```
