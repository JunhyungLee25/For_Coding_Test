## 1. 문제 분석

- **목표**: 0과 1로 이루어진 문자열 $S$에서 0과 1의 개수를 각각 절반으로 줄여 사전순으로 가장 빠른 문자열 $S'$ 만들기.
    
- **핵심 조건**:
    
    1. **상대적 순서 유지**: **문자를 재배치할 수 없으며**, 기존 문자열에서 일부를 '제거'하여 남은 문자들로만 구성해야 함.
        
    2. **사전순 최소화**: 두 문자열을 비교할 때 앞부분에 '0'이 더 많이 배치될수록 사전순으로 앞섬.
        

---

## 2. 문제 풀이 전략

### 사전순 최적화를 위한 그리디(Greedy) 전략

사전순으로 가장 빠른 문자열을 만들기 위해서는 문자열의 앞쪽에는 '0'이 오고, '1'은 최대한 뒤로 가야 한다. 

- **'1'의 제거**: 문자열의 앞쪽에 '1'이 있으면 사전순으로 뒤로 밀리게 된다. 따라서 '1'은 **문자열의 시작(인덱스 0)부터** 탐색하여 절반을 제거한다.
    
- **'0'의 제거**: 문자열의 뒤쪽에 '0'이 있으면 상대적으로 '1'이 앞쪽에 위치하게 된다. 따라서 '0'은 **문자열의 끝(마지막 인덱스)부터** 탐색하여 절반을 제거한다.
    

### 마킹(Marking)을 이용한 효율적 삭제

문자열에서 문자를 직접 삭제(`erase`)하면 남은 문자들을 당겨오는 연산으로 인해 $O(N)$의 시간이 소요되지만, 특정 값으로 치환하는 마킹 기법을 사용하여 성능을 최적화 하였다.

- **방법**: 제거 대상인 문자를 특정 기호나 숫자로 바꾼 뒤, 최종 출력 시 해당 문자가 아닌 경우만 출력한다.
    
- **시간 복잡도**: 전체 탐색 및 마킹에 $O(N)$, 출력에 $O(N)$이 소요되어 총 $O(N)$의 선형 시간에 해결 가능하다.

## 3. 최종 코드 및 동작 방식

### 핵심 로직 (Main Loop)

1. **Step 1: 개수 파악**: 전체 문자열을 순회하며 '0'과 '1'의 개수를 센 뒤, 각각 2로 나누어 지워야 할 개수를 구한다.
    
2. **Step 2: '1' 마킹**: 문자열의 왼쪽부터 순회하며 '1'을 발견하면 지워야 할 개수만큼 마킹하고 카운트를 증가시킨다.
    
3. **Step 3: '0' 마킹**: 문자열의 오른쪽부터 역순으로 순회하며 '0'을 발견하면 지워야 할 개수만큼 마킹하고 카운트를 증가시킨다.
    
4. **Step 4: 출력**: 문자열 전체를 순회하며 마킹되지 않은 문자만 차례대로 출력한다.
    

### 최종 코드

```c++
#include <iostream>
#include <string>

using namespace std;

int main(void) {
    // 입출력 속도 향상
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    string s;
    cin >> s;

    int zero = 0, one = 0;
    // 0과 1의 전체 개수 카운트
    for (int i = 0; i < s.length(); i++) {
        if (s[i] == '0') zero++;
        else one++;
    }

    // 절반씩 지워야 하므로 목표 개수 설정
    int target_zero = zero / 2;
    int target_one = one / 2;

    int cnt = 0;
    // 앞에서부터 '1'을 지워야 사전순으로 유리함
    for (int i = 0; i < s.length(); i++) {
        if (cnt == target_one) break;
        if (s[i] == '1') {
            s[i] = 'X'; // 마킹
            cnt++;
        }
    }

    cnt = 0;
    // 뒤에서부터 '0'을 지워야 앞쪽에 '0'이 많이 남음
    for (int i = s.length() - 1; i >= 0; i--) {
        if (cnt == target_zero) break;
        if (s[i] == '0') {
            s[i] = 'X'; // 마킹
            cnt++;
        }
    }

    // 마킹되지 않은 문자만 출력
    for (int i = 0; i < s.length(); i++) {
        if (s[i] != 'X') {
            cout << s[i];
        }
    }

    return 0;
}
```
