## 1. 문제 분석

이 문제는 첫 번째 단어와 나머지 단어들을 비교하여, 한 문자만 바꾸거나 추가 또는 삭제해서 첫 번째 단어와 같은 구성을 만들 수 있는 '비슷한 단어'의 개수를 구하는 문제이다.

- **핵심 로직 (3단계)**:
    
    1. **빈도수 계산**: 각 단어에 포함된 알파벳('A'-'Z')의 개수를 2차원 배열 `words[100][26]`에 저장한다.
        
    2. **차이 분석**: 첫 번째 단어(`words[0]`)와 비교 대상 단어(`words[i]`)를 알파벳별로 순회하며 개수 차이를 계산한다.
        
    3. **비슷한 단어 판별**:
        
        - **양수 차이(`p_cnt`)**: 첫 번째 단어에는 있고 비교 단어에는 부족한 문자의 총합을 구한다.
            
        - **음수 차이(`n_cnt`)**: 첫 번째 단어에는 없고 비교 단어에 더 많은 문자의 총합을 구한다.
            
        - 두 차이가 각각 1 이하(`p_cnt <= 1 && n_cnt <= 1`)일 때만 비슷한 단어로 간주한다.
            

---

## 2. 배운 점

- (1) **알파벳 빈도 배열 활용**: 문자를 직접 비교하는 대신 `wd[j] - 'A'`를 인덱스로 사용하여 0~25 범위의 배열에 빈도를 저장하는 방식이 효율적임을 확인했다.
    
- (2) **차이의 누적값 활용**: 단순히 개별 알파벳의 차이가 2 미만인지 보는 것이 아니라, 전체적인 부족분(`p_cnt`)과 초과분(`n_cnt`)을 나누어 합산함으로써 추가, 삭제, 교체 상황을 한 번에 체크할 수 있었다.
    
- (3) **조건의 추상화**: '한 글자를 바꾼다'는 것은 한 글자가 모자라고 한 글자가 남는 상태($p\_cnt=1, n\_cnt=1$)임을, '한 글자를 추가/삭제한다'는 것은 한쪽 차이만 1인 상태임을 논리적으로 도출해 냈다.

## 3. 최종 코드 및 동작 방식 정리

첫 번째 단어의 알파벳 구성을 기준으로 다른 단어들이 얼마나 동떨어져 있는지 파악하기 위해 `p_cnt`와 `n_cnt` 변수를 사용한다.

### 알파벳 구성 비교 로직

각 알파벳(`j`)에 대해 첫 번째 단어와 비교 단어의 개수 차이를 구한다.

- **`words[0][j] - words[i][j] > 0`**: 첫 번째 단어에 해당 알파벳이 더 많으므로, 비교 단어 입장에서 '보충해야 할' 개수이다. 이를 `p_cnt`에 더한다.
    
- **`words[0][j] - words[i][j] < 0`**: 비교 대상 단어에 해당 알파벳이 더 많으므로, '제거하거나 바꿔야 할' 개수이다. 이 값의 절댓값을 `n_cnt`에 더한다.
    
- **결과 판정**: 최종적으로 두 값이 모두 1 이하인 경우에만 정답 카운트를 올린다.
    

```c++
#include <iostream>
#include <string>
using namespace std;

int words[100][26];

int main(void) {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);

    int n, result = 0;
    cin >> n;

    string wd;
    for (int i = 0; i < n; i++) {
        cin >> wd;
        for (int j = 0; j < wd.size(); j++) {
            words[i][wd[j] - 'A']++;
        }
    }

    for (int i = 1; i < n; i++) {
        int p_cnt = 0; // 첫 번째 단어에 더 많은 문자 차이 누적
        int n_cnt = 0; // 비교 단어에 더 많은 문자 차이 누적

        for (int j = 0; j < 26; j++) {
            if (words[0][j] != words[i][j]) {
                int diff = words[0][j] - words[i][j];
                if (diff > 0) p_cnt += diff;
                else n_cnt -= diff; // diff가 음수이므로 빼서 양수로 만듦
            }
        }

        // 추가, 삭제, 교체, 동일 조건 모두 만족하는 범위
        if (p_cnt <= 1 && n_cnt <= 1) {
            result++;
        }
    }

    cout << result;
    return 0;
}
```
