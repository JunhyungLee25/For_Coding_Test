## 1. 문제 분석

이 문제는 일직선상에 세워진 탑들이 왼쪽으로 발사하는 레이저 신호를 어느 탑에서 수신하는지 찾아내는 자료구조 활용 문제이다.

- **핵심 로직 (3단계)**:
    
    1. **스택을 이용한 후보 관리**: 현재 탑의 레이저를 수신할 가능성이 있는 탑들만 스택에 유지한다. 왼쪽에서 오른쪽으로 탑을 하나씩 확인하며 스택을 갱신한다.
        
    2. **불필요한 정보 제거**: 현재 확인 중인 탑보다 높이가 낮은 탑들은 스택에서 제거(`pop`)한다. 현재 탑보다 낮은 탑들은 이후에 등장할 탑들이 보내는 레이저를 가로막을 수 없으므로 더 이상 필요하지 않다. -> a 높이 탑 다음에 a+1인 탑이 온다면 이후 탑들은 절대 a 높이 탑에 수신할 수 없다.
        
    3. **수신 탑 확인 및 저장**:
        
        - 스택이 비어있다면 왼쪽에 현재 탑보다 높은 탑이 없다는 의미이므로 0을 출력한다.
            
        - 스택이 비어있지 않다면 스택의 최상단(`top`)에 있는 탑이 현재 탑의 레이저를 수신하는 가장 가까운 탑이다.
            
        - 처리가 끝난 후 현재 탑의 정보를 스택에 추가(`push`)한다.

## 2. 배운 점

- (1) **스택의 활용**: 모든 원소를 이중 반복문으로 비교하는 $O(N^2)$ 방식 대신, 스택을 이용해 불필요한 원소를 빠르게 제거함으로써 $O(N)$의 시간 복잡도로 문제를 해결하는 법을 학습했다.
    
- (2) **pair를 활용한 데이터 관리**: 탑의 높이뿐만 아니라 위치(인덱스) 정보가 함께 필요할 때 `std::pair`를 사용하여 데이터를 쌍으로 묶어 관리하는 것이 효율적임을 이해했다.
    
- (3) **연산량을 줄이는 법**: $N$이 500,000에 달하는 문제에서는 이중 반복문이 아닌 한번의 반복문으로 모든 값을 처리할 수 있도록 해야한다. 따라서, 불필요한 정보를 없애고 최소한의 데이터로만 연산하도록 구현하는 것이 중요하다.

## 3. 최종 코드 및 동작 방식 정리

스택에는 `{높이, 인덱스}`를 저장한다. 새로운 탑이 들어올 때마다 스택 내부를 정돈하여 항상 내림차순 형태가 유지되도록 관리한다.

### 단조 스택 동작 원리

각 탑은 스택에 정확히 한 번 삽입되고, 최대 한 번 제거된다. 이로 인해 전체 연산 횟수는 $N$에 비례하게 된다.

- **제거 조건**: `stack.top().height <= current_height`
    
- **수신 조건**: `stack.top().height > current_height`
    
<br>

### 최종 구현 코드

```c++
#include<iostream>
#include<stack>
using namespace std;
stack<pair<int, int>> possible_top;
int main(void){
    ios_base :: sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    int n,height;
    cin >> n;
    for(int i=0; i<n; i++){
        cin >> height;
        while(!possible_top.empty() && possible_top.top().first < height) {possible_top.pop();}
        if(possible_top.empty()) cout << 0 << ' ';
        else cout << possible_top.top().second << ' ';
        possible_top.push({height,i+1});
    }
    return 0;
}
```
