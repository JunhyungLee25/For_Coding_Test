## 알고리즘 정리: 완전 탐색과 그리디

### 정의

완전 탐색(Brute-force)은 가능한 모든 경우의 수를 다 시도해보는 방법이며, 그리디(Greedy)는 매 순간 가장 최선의 선택을 하는 방법이다.

### 핵심 원리

- 이 문제에서는 1부터 숫자를 하나씩 키워나가는 **완전 탐색**의 형태를 띠면서도, 각 숫자 내에서 최대한 많은 문자를 순서대로 매칭시키는 **그리디**한 속성을 동시에 사용한다.
    
- 1, 2, 3, ... $N$까지 차례대로 검사하므로 처음 발견되는 $N$이 무조건 정답이 된다는 보장이 있다.
    

### 주요 특징

- **단순함:** 복잡한 예외 처리(앞에 붙이기, 뒤에 붙이기 등)를 할 필요가 없다.
    
- **안전성:** 모든 숫자를 순차적으로 확인하므로 논리적 오류가 발생할 확률이 적다.
    
- **시간 복잡도:** $N$이 증가함에 따라 자릿수만큼 연산이 늘어나지만, 입력 문자열의 길이가 짧아 충분히 제한 시간 내에 들어온다.
    

### 동작 방식

1. `pointer`가 입력 문자열 `number`의 끝에 도달할 때까지 숫자를 1부터 무한 루프를 돌린다.
    
2. 현재 숫자(`base`)를 문자열로 바꾼다.
    
3. 바꾼 문자열의 각 글자가 `number[pointer]`와 같은지 확인한다.
    
4. 같다면 `pointer`를 한 칸 옆으로 옮기고, 현재 숫자(`base`)의 다음 자릿수를 계속 확인한다.
    
5. `pointer`가 `number`의 끝에 가면 루프를 종료하고 그때의 `base`를 출력한다.

```c++
#include<iostream>
#include<string>
using namespace std;
int main(void){
    ios_base :: sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    string number;
    cin >> number;
    int base = 0;
    int pointer = 0;
    while(pointer < number.length()){
        base++;
        string target = to_string(base);
        for(int i=0; i<target.length(); i++){
            if(target[i] == number[pointer]){
                pointer++;
                if(pointer >= number.length()) break;
            }
        }
    }
    cout << base;
    return 0;
}
```

## 사고의 전환을 돕는 3단계

제미나이가 알려준 컴퓨팅적 사고방식

### 1. 관점을 바꿔라 (생성형 vs 매칭형)

나의 처음 생각은 "주어진 숫자로 어떻게 $N$을 **만들까**?"였다. 이것은 경우의 수가 너무 많아지는 '생성형' 사고다. 반대로 "1부터 커지는 숫자들 속에서 알맞은 숫자를 **찾을 수 있을까**?"라고 생각하면 문제가 '매칭형'으로 바뀐다.

### 2. 최솟값을 구하라 + 순차적인 흐름 + 부분 수열의 성질

문제에서 "1부터 N까지 차례대로"라는 조건과 "가장 작은 N을 찾아라"는 조건이 동시에 나온다는건 1부터 순서대로 입력값과 비교하여 처음 성공하는 순간이 최솟값이다.

문제에서 숫자들이 순서대로 나타나야 한다고 하는것은 전혁정인 **문자열 매칭** **부분수열** 문제의 특징이다. 따라서 원본을 하나씩 꺼내 입력값과 비교하는게 훨씬 자연스럽고, 직관적이다.
### 3. 제약 조건의 힌트 (Constraint)

이 문제에서 입력 문자열의 길이는 최대 3,000이다.

- $N$이 30,000 정도 된다고 해도, 1부터 30,000까지 숫자를 문자열로 변환해 검사하는 것은 컴퓨터 입장에서 눈 깜짝할 사이다.
    
- **"제약 조건이 생각보다 널널하다면, 가장 단순한 방법(Brute-force)부터 고민한다"** 는 원칙을 기억하라.
