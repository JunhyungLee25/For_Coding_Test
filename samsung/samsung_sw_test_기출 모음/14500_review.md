# 1. 문제 분석

이 문제는 $N \times M$ 격자판에서 4개의 칸을 연결하여 만든 '테트로미노'가 놓인 칸들의 합 중 최댓값을 구하는 시뮬레이션 및 완전 탐색 문제이다. 5종류의 테트로미노는 회전과 대칭이 가능하므로 **모든 경우의 수**를 고려해야 한다.

<br>

# 2. 핵심 로직 (3단계):

1. DFS를 이용한 경로 탐색: 테트로미노의 5가지 모양 중 4가지는 시작점에서 손을 떼지 않고 4칸을 이동하는 한 붓 그리기로 모두 표현이 가능하다. `stage` 변수를 통해 선택된 칸의 개수를 관리하며 4개에 도달할 때까지 사방 탐색을 수행한다.
    
2. **'ㅜ' 모양의 예외 처리**: 'ㅜ' 모양은 어느 한 지점에서 세 방향으로 뻗어나가는 구조이므로 일반적인 DFS 경로로는 탐색이 불가능하다. 이를 해결하기 위해 탐색 과정 중 2번째 칸(`stage == 2`)에서 위치를 이동하지 않고 다음 칸의 값만 더한 뒤 다시 현재 위치에서 탐색을 이어가는 분기 로직이 필요하다.
    
3. 백트래킹(Backtracking)을 통한 전수 조사: 격자의 모든 칸을 시작점으로 삼아 탐색하되, 한 번의 탐색이 끝나면 방문 표시(`visited`)를 다시 해제하여 다른 경로 탐색 시 해당 칸을 다시 사용할 수 있도록 한다.
 

<br>

# 3. 배운 점

1. DFS와 한 붓 그리기의 한계: 모든 연결된 모양이 DFS로 탐색 가능할 것이라고 쉽게 생각했는데, 'ㅜ' 모양처럼 차수가 3 이상인 정점이 포함된 경로는 일반적인 재귀 호출 구조에서 벗어난다는 점을 알게되었다. 이를 위해 특정 단계에서 위치를 고정하는 예외 로직을 구현하는 법을 알게 되었다.

2. 방문 배열 관리의 정밀함: `visited` 배열을 관리할 때 현재 칸이 아닌 다음에 이동할 칸(`ny, nx`)을 기준으로 체크하고 잠금/해제해야 함을 알게되었다.
 
3. 잘못 생각한 부분: 
	- 처음에는 `visited` 배열을 함수의 인자로 복사해서 전달하려 했으나, 이는 $500 \times 500$ 크기의 배열을 매번 복사하게 되어 심각한 성능 저하를 초래함을 알게 되었다. 
	- 백트래킹 시 **방문 해제 로직**을 누락하여 한 번 방문한 칸이 계속 방문되어있도록 하는 오류를 범했으나, 재귀 호출 직후 `false`로 되돌리는 처리를 통해 해결했다.


<br>

# 4. 최종 코드 및 동작 방식 정리
   
- 전체 격자를 순회하며 각 칸을 시작점으로 `func` 함수를 호출한다.
 

### func 함수 동작 방식:

- 종료 조건: `stage == 4`가 되면 현재까지 쌓인 `sum`과 전역 변수 `result`를 비교하여 최댓값을 갱신하고 종료한다.
    
- 사방 탐색: 상하좌우(`dy, dx`)를 살피며 격자 범위 내에 있고 아직 방문하지 않은 칸(`ny, nx`)을 찾는다.
    
- 예외 로직 ('ㅜ' 모양): `stage == 2`일 때, 다음 칸을 방문 처리만 하고 다음 재귀 호출 시 위치는 이동하지 않은 채(`y, x`) `stage`만 올린다. 이 과정이 'ㅜ' 모양의 중심점에서 가지를 치는 역할을 한다.
    
- 일반 로직: 다음 칸으로 위치를 이동하며 재귀를 이어간다.
    
- 백트래킹: 모든 재귀 호출이 끝난 후에는 `visited[ny][nx] = false`를 통해 방문 기록을 지워 다음 탐색에 지장이 없도록 한다.
    

```c++
#include<iostream>
using namespace std;

int n, m, result = 0;
int map[501][501];
bool visited[501][501];
int dy[4] = {-1, 0, 1, 0};
int dx[4] = {0, 1, 0, -1};

void func(int y, int x, int sum, int stage) {
    if (stage == 4) {
        if (result < sum) result = sum;
        return;
    }

    for (int i = 0; i < 4; i++) {
        int ny = y + dy[i];
        int nx = x + dx[i];

        if ((0 <= ny && ny < n) && (0 <= nx && nx < m) && !visited[ny][nx]) {
            // 'ㅜ' 모양 처리를 위한 특별 로직
            if (stage == 2) {
                visited[ny][nx] = true;
                func(y, x, sum + map[ny][nx], stage + 1);
                visited[ny][nx] = false;
            }

            // 일반적인 DFS 탐색
            visited[ny][nx] = true;
            func(ny, nx, sum + map[ny][nx], stage + 1);
            visited[ny][nx] = false;
        }
    }
}

int main(void) {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    cin >> n >> m;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> map[i][j];
        }
    }

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            visited[i][j] = true;
            func(i, j, map[i][j], 1);
            visited[i][j] = false;
        }
    }

    cout << result;
    return 0;
}
```
