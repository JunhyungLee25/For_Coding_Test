## 1. 문제 분석

이 문제는 토네이도의 이동 경로를 정확히 구현하고, 각 이동마다 발생하는 모래의 비산을 정밀하게 시뮬레이션하는 것이 핵심이다.

- **핵심 로직 (3단계)**:
    
    1. **토네이도 이동**: 토네이도는 특정 방향으로 `dist`만큼 이동한 후 방향을 바꾼다. 방향을 두 번 바꿀 때마다 `dist`가 1씩 증가하며, $(0, 0)$에 도달하면 즉시 종료한다.
        
    2. **모래 나누기**: 토네이도가 이동한 지점의 모래($y$)가 정해진 9개 지점의 비율과 나머지($\alpha$) 지점으로 흩어진다. 이때 상대 좌표 배열을 활용하여 복잡한 조건문 없이 처리한다.
        
    3. **격자 밖 모래 합산**: 비산되는 모래의 좌표가 격자 범위($0 \le r, c < N$)를 벗어나는 경우, 해당 모래의 양을 별도의 변수(`out_map`)에 누적한다.
        

---

## 2. 배운 점

- (1) **상대 좌표 배열의 효율성**: 방향에 따라 모래가 퍼지는 10개 지점의 좌표를 `sdy[4][9]`, `sdx[4][9]`와 같은 배열로 관리하여 코드의 가독성을 높이고 하드코딩으로 인한 실수를 방지하였다.
    
- (2) **토네이도 이동의 규칙성**: 이동 거리가 1, 1, 2, 2, 3, 3 ... 형태로 증가하는 규칙을 파악하여 `while` 루프와 `dist` 변수를 통해 직관적으로 구현하였다. 특히 마지막 $N-1$ 거리가 반복되는 구간에서 $(0, 0)$ 도달 시 즉시 종료하는 조건의 중요성을 배웠다. 
	- 잘못 생각한 부분: 3보다 큰 홀수에서는 마지막 N-1칸만 3번 반복인데. 이를 억지로 구현하려다 루프 변수가 복잡해졌었는데. N-1칸이 2번 나오고 다음에 N칸이 나오더라도 방향만 정확하다면 (0,0)에서 멈추기 때문에 문제 없다는 것을 알게 되어 코드를 간단하고 직관적이게 구현할 수 있었다.

---

## 3. 최종 코드 및 동작 방식 정리

토네이도의 이동을 `while`문 내에서 `dist`와 `idx`를 이용해 제어하며, 매 이동 시 `move_sand` 함수를 호출한다. `move_sand`는 미리 정의된 비율 배열과 상대 좌표 배열을 순회하며 모래를 격자 내부에 더하거나 밖으로 빼낸다.

### move_sand 함수

이 함수는 토네이도가 도착한 위치 `(y, x)`의 모래를 주변으로 흩뿌리는 역할을 한다.

- **작동 방식**:
    
    1. 현재 위치의 전체 모래 양(`tot_sand`)을 따로 저장한다.
        
    2. 9개 방향의 상대 좌표를 순회하며 각 비율(`rates[i]`)만큼의 모래를 계산한다.
        
    3. 계산된 모래가 격자 내부라면 `map`에 더하고, 외부라면 `out_map`에 누적하며, 비산된 총합(`tmp`)을 기록한다.
        
    4. 전체 모래(`tot_sand`)에서 `tmp`를 뺀 나머지를 알파 지점(`ay, ax`)에 배치한다.
        
    5. 비산이 끝난 원래 위치 `map[y][x]`는 0으로 초기화한다.
        

### 토네이도 이동 로직 (Main)

중앙 지점에서 시작하여 $(0, 0)$까지 반시계 방향으로 회전하며 이동한다.

- **작동 방식**:
    
    1. 초기 방향을 좌(`idx = 3`)로 설정하고 이동 거리 `dist = 1`로 시작한다.
        
    2. 동일한 거리로 두 번 이동하되, 한 번의 이동(거리 `dist`)이 끝날 때마다 방향을 반시계 방향으로 90도 회전시킨다.
        
    3. 한 칸씩 이동할 때마다 `r, c`를 갱신하고 `(0, 0)` 도달 여부를 확인한다.
        
    4. 두 번의 방향 전환이 완료되면 이동 거리 `dist`를 1 증가시킨다.
        

```c++
#include <iostream>
using namespace std;

int n;
int map[500][500];
int dy[4] = { -1, 0, 1, 0 }; // 0:상, 1:우, 2:하, 3:좌
int dx[4] = { 0, 1, 0, -1 };

int sdy[4][9] = {
    { 1, 1, 0, 0, 0, 0, -1, -1, -2 },  // 상
    { -1, 1, -2, 2, -1, 1, -1, 1, 0 }, // 우
    { -1, -1, 0, 0, 0, 0, 1, 1, 2 },   // 하
    { -1, 1, -2, 2, -1, 1, -1, 1, 0 }  // 좌
};
int sdx[4][9] = {
    { -1, 1, -2, 2, -1, 1, -1, 1, 0 }, // 상
    { -1, -1, 0, 0, 0, 0, 1, 1, 2 },   // 우
    { -1, 1, -2, 2, -1, 1, -1, 1, 0 }, // 하
    { 1, 1, 0, 0, 0, 0, -1, -1, -2 }   // 좌
};
int rates[9] = { 1, 1, 2, 2, 7, 7, 10, 10, 5 };
int out_map = 0;

void move_sand(int dir, int y, int x) {
    int tot_sand = map[y][x];
    int tmp = 0;

    for (int i = 0; i < 9; i++) {
        int ny = y + sdy[dir][i];
        int nx = x + sdx[dir][i];
        int sand = (tot_sand * rates[i]) / 100;

        if (ny >= 0 && ny < n && nx >= 0 && nx < n) map[ny][nx] += sand;
        else out_map += sand;
        tmp += sand;
    }

    int ay = y + dy[dir];
    int ax = x + dx[dir];
    int alpha_sand = tot_sand - tmp;

    if (ay >= 0 && ay < n && ax >= 0 && ax < n) map[ay][ax] += alpha_sand;
    else out_map += alpha_sand;

    map[y][x] = 0;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    cin >> n;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) cin >> map[i][j];
    }

    int r = n / 2, c = n / 2;
    int dist = 1, idx = 3;

    while (true) {
        for (int i = 0; i < 2; i++) {
            for (int j = 0; j < dist; j++) {
                r += dy[idx];
                c += dx[idx];
                move_sand(idx, r, c);
                if (r == 0 && c == 0) {
                    cout << out_map;
                    return 0;
                }
            }
            idx = (idx + 3) % 4; // 반시계 회전
        }
        dist++;
    }
}
```
