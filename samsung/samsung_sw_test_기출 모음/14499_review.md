## 1. 문제 분석

이 문제는 격자판 위에서 주사위를 굴리며 주사위의 상태 변화와 격자판의 숫자를 조건에 맞게 갱신하는 시뮬레이션 문제이다.

- **핵심 로직 (3단계)**:
    
    1. **이동 가능 여부 확인**: 명령받은 방향으로 주사위를 굴렸을 때 격자판의 범위를 벗어나는지 확인한다. 범위를 벗어나면 해당 명령을 무시하고 출력도 하지 않는다.
        
    2. **주사위 회전 (상태 갱신)**: 주사위의 6개 면을 고정된 인덱스로 정의하고, 굴리는 방향에 따라 각 위치의 값을 시프트 연산과 유사하게 교체한다. 이때 굴리는 방향과 수직인 두 면의 값은 변하지 않는다.
        
    3. **값 복사 및 출력**:
        
        - 이동한 칸의 숫자가 0이면 주사위 바닥면의 숫자를 칸에 복사한다.
            
        - 0이 아니면 칸의 숫자를 주사위 바닥면으로 복사하고 칸의 숫자를 0으로 만든다.
            
        - 매 이동 후 주사위의 윗면 숫자를 출력한다.
            

---

## 2. 배운 점

- (1) **주사위 면 관리 기법**: 주사위의 전개도를 복잡하게 추적하는 대신, 6개의 면(위, 아래, 동, 서, 남, 북)을 배열의 고정된 인덱스로 관리하는 것이 구현에 있어 훨씬 직관적이다.
    
- (2) **임시 변수를 활용한 스왑(Swap)**: 회전 시 4개의 면이 동시에 변하므로, 변수를 활용하여 값이 덮어씌워지기 전에 보관하는 과정의 중요하다.
    
- (3) **좌표계 매핑 주의**: 문제에서 주어진 방향(1:동, 2:서, 3:북, 4:남)과 실제 배열의 행/열 인덱스 변화(`dy`, `dx`)를 정확히 일치시키는 과정에서 인덱스 실수를 하지 않는것이 중요하다.

## 3. 최종 코드 및 동작 방식 정리

주사위의 면을 `dice[6]` 배열로 관리하며, `dice[0]`을 윗면, `dice[5]`를 바닥면으로 설정한다. 명령이 들어올 때마다 방향을 확인하여 주사위 값을 회전시키고 지도와의 상호작용을 처리한다.

### 주사위 회전 로직

각 방향으로 굴릴 때마다 이동 경로에 포함되는 4개 면의 값을 순차적으로 교체한다.

- **동쪽(1)**: 위 -> 동, 동 -> 아래, 아래 -> 서, 서 -> 위
    
- **서쪽(2)**: 위 -> 서, 서 -> 아래, 아래 -> 동, 동 -> 위
    
- **북쪽(3)**: 위 -> 북, 북 -> 아래, 아래 -> 남, 남 -> 위
    
- **남쪽(4)**: 위 -> 남, 남 -> 아래, 아래 -> 북, 북 -> 위
    

### 주사위와 지도의 상호작용

주사위가 이동한 후 바닥면(`dice[5]`)과 지도(`map[ny][nx]`)의 값을 문제 조건에 따라 갱신한다.


```c++
#include <iostream>
#include <vector>
using namespace std;

int n, m, r, c, k;
int map[20][20];
int dice[6] = { 0, }; // 0:위, 1:남, 2:동, 3:서, 4:북, 5:바닥

// 문제 방향: 1:동, 2:서, 3:북, 4:남
int dr[] = { 0, 0, 0, -1, 1 };
int dc[] = { 0, 1, -1, 0, 0 };

void roll(int dir) {
    int d[6];
    for (int i = 0; i < 6; i++) d[i] = dice[i];

    if (dir == 1) { // 동
        dice[0] = d[3]; 
        dice[2] = d[0]; 
        dice[5] = d[2]; 
        dice[3] = d[5];
    }
    else if (dir == 2) { // 서
        dice[0] = d[2]; 
        dice[3] = d[0]; 
        dice[5] = d[3]; 
        dice[2] = d[5];
    }
    else if (dir == 3) { // 북
        dice[0] = d[1]; 
        dice[4] = d[0]; 
        dice[5] = d[4]; 
        dice[1] = d[5];
    }
    else if (dir == 4) { // 남
        dice[0] = d[4]; 
        dice[1] = d[0]; 
        dice[5] = d[1]; 
        dice[4] = d[5];
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    cin >> n >> m >> r >> c >> k;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) cin >> map[i][j];
    }

    for (int i = 0; i < k; i++) {
        int dir;
        cin >> dir;
        int nr = r + dr[dir];
        int nc = c + dc[dir];

        if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;
        roll(dir);

        if (map[nr][nc] == 0) {
            map[nr][nc] = dice[5];
        }
        else {
            dice[5] = map[nr][nc];
            map[nr][nc] = 0;
        }
        r = nr; c = nc;
        cout << dice[0] << "\n";
    }
    return 0;
}
```
