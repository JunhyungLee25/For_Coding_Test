## 문제 복기

- 사다리를 2차원 배열로 설정하고 index 개념을 정확히 이해를 못해서 매우매우 헷갈렸다.
### 1. 기둥과 팔 (배열의 진짜 의미)

- **기둥 (세로선):** 문제에서 세로선이 `N`개라고 했다. 현재 작성한 코드는 0부터 시작하므로, 기둥의 번호는 `0`번, `1`번, `2`번 ... `N-1`번 기둥이 있다. (예: N이 5라면 0, 1, 2, 3, 4번 기둥이 있다.)
    
- 팔 (가로선, `map` 배열): 배열의 한 칸인 `map[r][c]`를 '$c$번 기둥이 $r$층에서 오른쪽으로 뻗은 팔'이라고 상상해 보자.
    
    - `map[1][0] = 1` : 1층에서, 0번 기둥이 **오른쪽**(1번 기둥 방향)으로 팔을 뻗어서 다리를 만들었다는 뜻이다.
        

### 2. check 함수 이해하기 (사다리 타고 내려가기)

내가 현재 `c`번 기둥에 매달려 밑으로 내려간다고 상상해 본다. 갈림길(다리)을 만나면 옆 기둥으로 건너가야 한다.

``` c++
if(map[r][c]==1) c++;
else if(c>0 && map[r][c-1]==1) c--;
```

- **오른쪽으로 건너갈 때 (`map[r][c] == 1`):**
    
    현재 내가 매달린 기둥(`c`)이 오른쪽으로 팔을 뻗었는지 확인한다. 팔이 있다면(`1`이라면), 그 팔을 타고 오른쪽 기둥으로 건너간다. 내 위치는 `c + 1`이 되므로 `c++`를 해준다.
    
- **왼쪽으로 건너갈 때 (`map[r][c-1] == 1`):**
    
    내 기둥에는 팔이 없지만, **내 왼쪽 기둥(`c-1`)이 나를 향해 오른쪽으로 팔을 뻗었을 수 있다.** 그래서 `c-1`번 기둥의 상태(`map[r][c-1]`)를 확인하는 것이다. 왼쪽 기둥이 뻗은 팔이 있다면, 그 팔을 타고 왼쪽으로 건너가야 하므로 내 위치는 `c--`가 된다.
    

### 3. Ladder 함수 이해하기 (새로운 팔 만들기)

이제 사다리에 새로운 가로선을 추가하는 부분을 본다.

```c++
for(int c=sc; c<N-1; c++){
    if(map[r][c]==0){
        if((c==0 || map[r][c-1]==0) && map[r][c+1]==0){
            map[r][c]=1; // 팔을 뻗는다!
            // ... 생략 ...
```

- **`c < N-1`인 이유:**
    
    마지막 기둥(`N-1`번 기둥)은 오른쪽에 더 이상 다른 기둥이 없다. 허공을 향해 팔을 뻗을 수 없으므로, 오른쪽으로 팔을 뻗을 수 있는 기둥은 그 전 기둥(`N-2`)까지만 가능하다. 그래서 `c < N-1`까지만 반복하는 것이다.
    
- **팔을 뻗기 위한 안전 검사:**
    
    다리가 서로 연속해서 닿으면 안 된다는 규칙이 있다. 내가 지금 `c`번 기둥에서 오른쪽으로 팔을 뻗으려 한다면 주변을 살펴야 한다.
    
    1. `map[r][c] == 0` : 내가 지금 팔을 뻗을 자리가 비어 있는가?
        
    2. `map[r][c-1] == 0` : 내 왼쪽 기둥(`c-1`)이 이미 나한테 팔을 뻗고 있지 않은가?
        
    3. `map[r][c+1] == 0` : 내 오른쪽 기둥(`c+1`)이 이미 그 오른쪽으로 팔을 뻗고 있지 않은가?
        
        이 모든 조건이 안전할 때만 비로소 내 팔을 뻗을 수 있다 (`map[r][c] = 1`).
        
- `Ladder(r,c+2,cnt+1,limit)`로 넘기는 이유
	문제 조건에서 가로선은 연속해서 놓일 수 없으므로 효율성을 위해 놓은 칸의 다다음칸 부터 검사를 시작한다.

---

`map[r][c]`는 c번 기둥이 오른쪽으로 뻗은 팔이다라는 단 하나의 문장만 기억하면 모든 인덱스 계산이 논리적으로 맞아떨어짐을 알 수 있다.


## 최종 코드

```c++
#include<iostream>
using namespace std;

int N,H,M;
int map[31][11];

bool check(){
    for(int i=0; i<N; i++){
        int c=i;
        for(int r=1; r<=H; r++){
            if(map[r][c]==1) c++;
            else if(c>0 && map[r][c-1]==1) c--;
        }
        if(c!=i) return false;
    }
    return true;
}
void Ladder(int sr, int sc, int cnt, int limit){
    if(cnt==limit){
        if(check()){
            cout << cnt;
            exit(0);
        }
        return ;
    }
    for(int r=sr; r<=H; r++){
        sc = (r==sr) ? sc : 0;
        for(int c=sc; c<N-1; c++){
            if(map[r][c]==0){
                if((c==0 || map[r][c-1]==0) && map[r][c+1]==0){
                    map[r][c]=1;
                    Ladder(r,c+2,cnt+1,limit);
                    map[r][c]=0;
                } 
            }
        }
    }
}
int main(void){
    cin >> N >> M >> H;
    for(int i=0; i<M; i++){
        int rr,cc;
        cin >> rr >> cc;
        map[rr][cc-1]=1;
    }
    for(int i=0; i<=3; i++){
        Ladder(0,0,0,i);
    }
    cout << -1;
    return 0;
}
```
