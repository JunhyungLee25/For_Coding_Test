### 정의

**초기화**란 변수나 배열을 선언함과 동시에 특정한 값을 할당하는 과정을 말한다. C++에서 지역 변수로 선언된 배열은 초기화하지 않으면 쓰레기 값이 들어있어 논리 오류의 주된 원인이 된다.

### 핵심 원리

- **정적 초기화:** 컴파일 시점에 중괄호`{}`를 사용하여 값을 채운다.
    
- **메모리 복사:** `memset`을 이용해 메모리 블록 단위로 값을 빠르게 채운다.
    
- **반복자 기반:** `std::fill`을 사용하여 지정된 범위의 모든 요소를 특정 값으로 설정한다.
    

### 주요 특징

- **중괄호`{0}`:** 가장 간단하지만 0 이외의 값으로 전체를 채울 수는 없다.
    
- **`memset`:** 속도가 매우 빠르지만, 바이트 단위로 처리하기 때문에 0이나 -1 이외의 값(예: 1, 100)을 넣으면 예상치 못한 값이 저장된다.
    
- **`std::fill`:** 모든 자료형과 모든 값에 대해 안전하게 동작하며, 가독성이 높다.
    

### 구현 방법 및 예시

#### 1. 1차원 배열 초기화

```c++
int arr[100] = {0}; // 전체 0으로 초기화
int arr2[100] = {1, 2}; // 앞의 두 개는 1, 2 나머지는 모두 0

#include <algorithm>
fill(arr, arr + 100, 7); // 전체를 7로 초기화
```

#### 2. 2차원 배열 초기화

```c++
int board[10][10] = {0}; // 전체 0으로 초기화

#include <cstring>
memset(board, -1, sizeof(board)); // 전체를 -1로 초기화 (0, -1만 가능)

#include <algorithm>
// 2차원 배열을 특정 값(예: 99)으로 초기화
fill(&board[0][0], &board[0][0] + (10 * 10), 99);
```

#### 3. std::vector 초기화

```c++
#include <vector>
using namespace std;

// 크기 10을 5로 초기화
vector<int> v(10, 5); 

// n x m 크기의 2차원 벡터를 0으로 초기화
vector<vector<int>> matrix(n, vector<int>(m, 0));

// 이미 생성된 벡터를 다시 초기화
fill(v.begin(), v.end(), 0);
```

### 주의 사항

- `memset`을 사용할 때는 반드시 `<cstring>` 헤더를 포함해야 한다.
    
- 2차원 배열에 `std::fill`을 쓸 때 `board[0]`부터 `board[9]`까지 범위를 정확히 지정해야 하며, 보통 `&board[0][0]` 주소를 활용하는 방식이 안전하다.
